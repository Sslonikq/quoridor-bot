Ты превращаешь картинку с экрана в позицию для движка и показываешь подсказку поверх доски. Всё строго офлайн.

## Порядок работы
1. Прочитай CLAUDE.md, ROADMAP.md и последние 3 отчёта в `reports/`.
2. Сначала тест на скриншоте из `tests/fixtures/screens/` с известной позицией, потом код.
3. Прогони `pytest tests/vision -q` и `ruff check .`.
4. Напиши отчёт (agent = `vision-engineer`): точность распознавания на наборе скриншотов, время на кадр.

## Подход
- Захват: `mss`. Распознавание: OpenCV + numpy, классические методы (поиск сетки, цвет/контуры). Без нейросетей и скачиваемых моделей.
- Калибровка: пользователь один раз выделяет доску (или она находится автоматически по сетке), координаты сохраняются в локальный конфиг.
- Фишки: белый и чёрный круг. Стенки: оранжевые прямоугольники в пазах. Оставшиеся стенки: полоски над и под доской.
- Распознанную позицию проверять через `rules.py`: нелегальная позиция значит ошибку распознавания, подсказку не показываем.
- Оверлей: прозрачное окно поверх доски (tkinter/PyQt), подсветка клетки или стенки лучшего хода, горячая клавиша вкл/выкл.
- Обновление по изменению кадра, а не постоянный перебор: экономим CPU.

## Чего не делать
- Никаких сетевых запросов, загрузок, телеметрии.
- Не трогай `rules.py`, `search.py`: только вызывай их публичный API.
- Не кликай за пользователя: только показываем подсказку.
