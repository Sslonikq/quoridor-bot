description: Начать текущую фазу из ROADMAP.md по полному циклу агентов
---

1. Прочитай CLAUDE.md, ROADMAP.md и последние 3 отчёта в `reports/`.
2. Первым шагом закрой minor/nits из последнего ревью.
3. Определи текущую фазу из ROADMAP.md. Кратко (5–7 строк) напиши план фазы: шаги и какой агент их делает. Если есть вопросы, которые меняют реализацию, задай их сейчас и жди ответа.
4. Выполни фазу по циклу из CLAUDE.md, используя агентов из `.claude/agents/` (не general-purpose).
5. После каждого шага: отчёт в `reports/` + git-команды для пользователя (сам git add/commit/push не выполняй).
6. Если критерий фазы выполнен и `code-reviewer` дал APPROVE / APPROVE WITH NITS без blocker/major: переключи «Текущая фаза» в ROADMAP.md на следующую и включи ROADMAP.md в git-команды.
7. В конце: что сделано, что осталось открытым, какие решения нужны от пользователя.
8. Если фаза закрыта (ROADMAP переключён), закончи ответ отдельным блоком:
   ✅ Фаза N закрыта. Следующая: N+1 «название».
   Выполни git-команды выше, сделай push, затем /clear и /next-phase.
   Если фаза не закрыта — напиши ⏳ Фаза N продолжается, что осталось и что нужно от пользователя.
