## Замечания

### nit
1. **[nit] `quoridor/analyzer/static/app.js:133,102,108`:** `play()` добавляет ход в `line` до ответа сервера. Если `/api/state` упал без `bad_move` (403, сеть), `line` содержит неподтверждённый ход, а `pos` и доска остаются старыми. После этого «Копировать ходы» и список ходов показывают ход, которого нет на доске. → В ветках «нет связи» / `!res.ok` без `bad_move` откатывать последний ход (или держать подтверждённую длину `line` отдельно).
2. **[nit] `app.js:188`:** при выключении подсказки делается `seq++`. Если в этот момент в полёте `/api/state` после хода, его ответ отбрасывается (`my !== seq`) и доска не обновляется до следующего действия. Окно узкое (state отвечает за мс). → Для отмены анализа держать отдельный счётчик, `seq` оставить для state.
3. **[nit] `app.js:55-57`:** `pos.last` подсвечивается только для хода пешкой. Последняя поставленная стенка не выделяется, хотя сервер присылает её геометрию. → Обвести `wallRect(last)` (UX, можно в фазе 8).
4. **[nit] `tests/analyzer/test_server.py:216`:** 0050 взял позиции 20–51. Худшие по замеру 0048 позиции n = 3 и 18 в набор не попали. Запас большой (ответы ≤ 2.01 с), так что риск низкий. → При случае добавить 3 и 18 в параметризацию.
5. **[nit] `quoridor/analyzer/server.py:97`:** `_drain` при раннем отказе синхронно вычитывает до 1 МБ (`16 * MAX_BODY`). Локально это безвредно, ограничено `timeout = 10`. Оставить как есть, только знать о поведении.
6. **[nit] из 0048, ещё открыты:** nit 2 (отмена на сервере при выключении подсказки, `/api/cancel`), 5 (`search_root`, ai-engineer), 8 (Google Fonts в `docs/mockups/analyzer.html`). Перенести в бэклог фазы 8.
7. **[nit] отчёты:** 0049 и 0050 заполнены по шаблону, все разделы на месте. В 0049 честно указано, что UI в браузере не проверялся. Это единственный непроверенный кусок фазы.
