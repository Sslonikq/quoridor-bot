### Корректность (разбор)
- **`endgame.py`.**
  - `adj`/`inv` взаимно обратны на достижимых значениях.
  - `can_reach`: d ≤ k + J. Прыжок даёт не больше 2 шагов и требует манхэттенского расстояния 1. Расстояние меняется не больше чем на 2 за полуход. i0 = ⌈(man − 1 − 2·t0)/4⌉, оценка верная и консервативная.
  - Границы `hi = MATE−3` (победа на 1-м полуходе уже проверена) и `lo = −(MATE−2)` точные.
  - Правила TT проверены по монотонности V_r по глубине:
    - EXACT-мат действует при r ≥ n, иначе 0;
    - EXACT 0 действует при r ≤ td;
    - LOWER tv ≤ 0 при r ≤ td, tv > 0 при r ≥ td;
    - UPPER симметрично.

    Всё корректно.
  - Корень, взятый из LOWER-записи, всё равно даёт точную мат-дистанцию: предыдущая итерация доказала 0 на r−1.
  - «Тихие» стенки без BFS легальны, потому что кратчайшие пути обоих не задеты.
- **`eg_search`.**
  - Итеративный порт эквивалентен рекурсии: окно идёт через `inv`, обрыв по узлам возвращает 0 без записи в TT, ход корня берётся из TT.
  - Границы: ходов ≤ 5 + 128 при буфере 256; ply ≤ 161 при стеке `MAX_PLY + 2 = 164` (глубину ограничивает `solve`); слоёв ≤ 82.
  - Ключ: u0, u1 < 128 и w ≤ 10 укладываются в поля 7/7/4/4 бит; умножения uint64 по модулю, как в Python.
  - Совпадение ядер до числа узлов подтверждено тестами.
- **`reserve_combo`.**
  - Знаки в `Searcher._reserve_combo_term` и в `kernels._eval` совпадают: плоский `_reserve_threat` возвращается со знаком, обратным `reserve_term`.
  - `ct[player, cell, 2 + j]` = `ds[j−1]`; размер `ct` равен `3 + combo_levels`.
  - `potential` ограничен `combo_k` и при более глубоком мемо не меняется (есть тест).
- **`mcts.py`.**
  - Решатель в корне: отмена даёт `MCTSCancelled(0)` и дерево не трогает; доказанный ход сбрасывает дерево; недоказанный оставляет MCTS остаток дедлайна.
  - `keep_on_cancel` оставляет дерево согласованным: отмена срабатывает между пачками или симуляциями.
  - `ST_FULL` и `grow()` с запасом +2 узла / +256 рёбер; `MAX_PATH` охраняется.
- **Анализатор.**
  - `_mcts_shared` читается и пишется только под `_MCTS_LOCK`, `reset_mcts_tree` тоже под замком; при таймауте запрос ищет на отдельном экземпляре.
  - `bot` проверяется по белому списку `("v4", "v5", "mcts")`; `time` — число в (0; 30], без bool и NaN.
  - `HOST = "127.0.0.1"`, есть защита Host/Origin.
- **Офлайн и чистота.**
  - В `quoridor/` нет импортов `socket`, `urllib`, `requests`, `http.client`, нет внешних URL в `static/`.
  - `rules.py`, `paths.py`, `state.py`, `notation.py` в фазе 9 не менялись (`git log 708bb0f..HEAD`). Нотация в новых модулях не встречается, коды ходов внутренние.
