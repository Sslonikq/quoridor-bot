# 0078 · Анализатор: переключатель времени «быстро 1 с / нормально 5 с / глубоко 20 с»

- **Дата:** 2026-10-17
- **Агент:** ui-engineer
- **Статус:** done
- **Связанные отчёты:** 0072

## Задача
Фаза 9, пункт 8: кнопка «Глубокий анализ» становится режимом «глубоко»; три режима времени подсказки, выбор в localStorage (try/catch), по умолчанию «нормально». Живая глубина и отмена (0072) работают во всех режимах.

## Что сделано
- Вместо кнопки `bDeep` в панели три кнопки-режима (`mode_fast`, `mode_normal`, `mode_deep`: 1 / 5 / 20 с), активный подсвечен.
- Каждая подсказка (после хода, навигации, включения подсказки) считается за время выбранного режима. Прогресс-полоса, «N из S с, глубина D» и Esc теперь для любого режима (переименовано `deep` -> `live`, `startDeep` -> `startAnalysis`, `cancelDeep` -> `cancelAnalysis`).
- Клик по другому режиму: сохраняет выбор и сразу пересчитывает позицию (если подсказка включена, нет разбора и партия не окончена). Клик по активному режиму во время расчёта отменяет его, в простое пересчитывает.
- Esc: отмена поиска на клиенте и явный `/api/cancel`; новый расчёт не запускается (раньше возвращалась обычная подсказка, теперь режим может быть любым, иначе цикл).
- Результат подписан режимом: «Глубоко, 20 с: глубина N, …».
- `localStorage` (ключ `quoridor.analyzer.mode`): чтение и запись в try/catch; неизвестное значение (в т.ч. `constructor`) -> «нормально».
- Разбор партии не менялся: свой ввод «Бюджет, с/позицию», подсказка берётся из разбора как раньше.
- Сервер не менялся: `time` 1 / 5 / 20 уже допустимы (до 30); добавлен тест.

## Проверка
- `pytest -q -m "not slow" tests/analyzer` -> 189 passed, 1 failed в первом прогоне (мой тест прогресса), исправлен; `test_client_js.py` -> 18 passed. Полный прогон analyzer после правки не повторялся (CPU занят матчами), менялись только харнесс и его тесты.
- `ruff check` и `ruff format --check` для `quoridor/analyzer`, `tests/analyzer` -> ok.
- Slow-тесты не запускались. Вручную в браузере не проверял (Node-харнесс).

## Решения и почему
- Esc без перезапуска: иначе в режиме «глубоко» отмена сразу запускала бы тот же расчёт.
- Поведение умолчания бота не менялось; клиентское умолчание «нормально» = прежние 5 с.

## Breaking changes
Кнопки `bDeep` больше нет; `ana.deep` заменено на `ana.mode`/`ana.secs` (только клиент).
