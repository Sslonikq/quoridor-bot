## Что проверено
- **W/L/D и цвета.** `outcome_for_a` и `_tally` считают верно. `as_white`/`as_black` фильтруют по `a_color`. Сумма по цветам равна итогу. Тесты на заглушках дают 6/0/0 (3+3) и 0/5/0 (3+2).
- **Баланс цветов.** A белыми при чётном индексе, поэтому при нечётном `--games` у A на одну белую партию больше. Это видно в выводе. Тест покрывает n = 0, 1, 2, 7, 10.
- **Уилсон.** Формула верная: центр `(p + z²/2n)/(1 + z²/n)`, полуширина `z·sqrt(p(1-p)/n + z²/4n²)/(1 + z²/n)`, результат обрезается до [0, 1]. Контрольные значения 50/100 → [0.4038, 0.5962] и 100/100 → нижняя граница n/(n+z²) = 0.963 сходятся.
- **Детерминизм seed.** У каждой партии свой seed `seed*1_000_003 + i`, бот A получает `2s`, бот B `2s+1`. Проверено в процессе и через subprocess. Время хода в ходы не просачивается.
- **Лимит ходов → ничья.** Победа проверяется раньше лимита, поэтому победа на последнем разрешённом полуходе засчитывается как победа. Проверил вручную: runner против idler, `max_moves = plies` → победитель есть. Порядок проверок (winner, затем limit) совпадает с `cli.play`. Расхождения правил нет: обе функции применяют ходы через проверяющий `apply_move`.
- **Ошибки и коды возврата.** Неизвестный бот → 2, сообщение в stderr, без traceback. `--games 0` / `--max-moves 0` → 2. Ошибка argparse → 2. Успех → 0.
- **Чистота.** `run_match`/`play_game` не делают I/O, печатает только `main`. `perf_counter` используется только для замера.
- **Нотация.** `arena.py` импортирует только `notation.format_move`. Тест воспроизводит лог через `parse_move`.
- **Офлайн.** В `quoridor/` нет сетевых импортов (grep socket/urllib/requests/http пуст).
- **Горячие пути.** Не затронуты, на ход добавляется только `format_move`.
- **Отчёты 0015–0017.** Все по шаблону, Git-секции перечисляют файлы явно.
