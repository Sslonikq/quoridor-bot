## Правила
- Для дружеских партий с согласия соперника. Не для игр против незнакомых людей.
- Всё работает офлайн: никаких сетевых запросов, API, телеметрии.
- Работаем строго по текущей фазе; задачи из следующих фаз записываем в «Следующий шаг» отчёта.
- Фаза закрывается отчётом `code-reviewer` с вердиктом APPROVE; после этого обновляем «Текущая фаза».
- README.md не трогаем до фазы 8.
